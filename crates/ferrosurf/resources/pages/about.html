Conectar un agente MCP

FerroSurf expone sus pestañas y herramientas mediante el Model Context Protocol. Para Claude Desktop, añade esto a tu claude_desktop_config.json:

{
  "mcpServers": {
    "ferrosurf": {
      "command": "ferrosurf",
      "args": ["--mcp-stdio"]
    }
  }
}

O conecta cualquier cliente compatible al endpoint HTTP:

{{MCP_URL}}

Pulsa Ctrl+J para abrir el asistente IA integrado.
